# 평영 발차기 추진 원리 영상

`breaststroke_kick_propulsion.mp4` (1280×720, 30fps, 약 89초) — 위에서 내려다본 시점

| 구간 | 내용 |
|---|---|
| 0–5초 | 타이틀 |
| ① 5–21초 | 동작: 리커버리 → 킥(발목 플렉스, 바깥→뒤→안쪽 반원) → 글라이드, 발바닥 궤적, 옆에서 본 발목 모양 |
| ② 21–41초 | 작용·반작용: 발바닥이 물을 미는 힘 / 물이 되미는 힘, 추진력·브레이크, 시간에 따른 추진력 그래프 |
| ③ 41–62초 | 물의 흐름: 물 입자, 발마다 생기는 소용돌이 쌍(입체로는 소용돌이 고리), 두 갈래 뒤쪽 제트, 리커버리 브레이크 |
| ④ 62–78초 | 발목 플렉스 vs 포인트 추진력 비교 |
| 78–89초 | 정리 |

## 모델
- `kick_model.py`: 위에서 본 다리 관절 키프레임(주기적 Catmull-Rom 보간), 분절별 압력 항력으로 물의 힘 추정
  (아래로 선 정강이는 모든 방향 항력, 발은 플렉스할수록 수평면에서 물을 받는 면적이 커짐),
  발이 물에 가한 운동량만큼 와류쌍을 넣는 와류법(vortex blob) 후류 시뮬레이션.
- `render.py`: matplotlib + ffmpeg 렌더러. `python3 render.py` 로 다시 만들고,
  `PREVIEW=10,20 python3 render.py` 로 해당 시각 프레임만 PNG로 확인한다.

수평면만 다룬 단순화한 교육용 모델이며, 힘의 크기는 상대값이다.
