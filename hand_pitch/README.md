# 손바닥 기울기와 힘의 방향

`hand_pitch_force.mp4` (1280×720, 30fps, 73초)

| 구간 | 내용 |
|---|---|
| 0–5초 | 타이틀 |
| ① 5–19초 | 손을 똑바로 뒤로 밀 때: 항력·양력·합력, 손바닥을 기울이면 힘이 옆으로 샘 |
| ② 19–43초 | 손이 45° 비스듬히 움직일 때: 손 움직임 정면 vs 정확히 뒤 vs 최적 기울기 (그래프로 탐색) |
| ③ 43–62초 | 스컬링: 손을 옆으로만 움직여도 양력으로 앞으로 가는 힘 |
| 62–73초 | 정리 |

## 모델
- `hand_model.py`: 손을 얇은 판으로 보고 받음각에 따른 항력·양력 계수
  `CD = 0.1 + 1.1 sin²α`, `CL = 1.0 sin 2α` (손 모형 실험값의 모양을 따른 근사)로 힘을 계산.
- `render.py`: 판 주위 퍼텐셜 흐름(주코프스키 사상 + 쿠타 조건, 순환은 위 양력계수에 맞춤)으로 물 입자를 움직이고
  matplotlib + ffmpeg 로 렌더링. `PREVIEW=10,20 python3 render.py` 로 프레임 PNG만 확인할 수 있다.

단순화한 2차원 교육용 모델이며 힘은 상대값이다.
