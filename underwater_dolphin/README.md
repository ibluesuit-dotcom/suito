# 스타트 후 수중 돌핀킥

`underwater_dolphin_kick.mp4` (1280×720, 30fps, 96초)

| 구간 | 내용 |
|---|---|
| 0–5초 | 타이틀 |
| ① 5–24초 | 스타트 전체 흐름(출발·비행 → 글라이드 → 돌핀킥 → 자유형), 거리–속도 그래프, 바로 떠올라 자유형과 비교 |
| ② 24–41초 | 돌핀킥 동작: 가슴 → 골반 → 무릎 → 발끝으로 전달되는 물결, 발끝 궤적 |
| ③ 41–58초 | 추진력: 발·정강이에 걸리는 힘, 다운킥 75% / 업킥 25%, 발 77% / 정강이 18% |
| ④ 58–74초 | 물의 흐름: 소용돌이 쌍과 밀려나는 물 |
| ⑤ 74–86초 | 잘하는 방법과 안전 주의(과호흡 후 잠영 금지) |
| 86–96초 | 정리 |

## 모델
- `dolphin_model.py`
  - 몸을 손끝–발끝 마디 사슬로 보고 진행파 `y = A(s)·sin(k·s − ω·t)` 로 움직임(다운킥이 더 빠르도록 시간 비대칭),
    분절별 압력 항력으로 추진력 추정, 발·정강이가 물에 준 운동량만큼 와류쌍을 넣는 와류법 후류.
  - 스타트 구간 속도: 1차원 운동 방정식 `m·dv/dt = T − k·v²` (글라이드·돌핀킥·수면 자유형의 항력 계수를 다르게 두어
    수면의 조파 저항을 반영). 입수 속도 4.8 m/s, 15 m 도착 잠영 5.46초 vs 바로 수면 5.87초.
- `render.py`: matplotlib + ffmpeg 렌더러. `PREVIEW=10,20 python3 render.py` 로 프레임 PNG만 확인할 수 있다.

단순화한 교육용 모델이며, 수치는 모델 값이다.
