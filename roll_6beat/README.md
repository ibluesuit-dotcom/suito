# 자유형 롤링과 6비트 킥 타이밍

`roll_6beat_timing.mp4` (1280×720, 30fps, 69초)

| 구간 | 내용 |
|---|---|
| 0–5초 | 타이틀 |
| ① 5–21초 | 롤링: 어깨 약 40°, 골반 약 25°, 머리는 고정, 다리는 골반을 따라 비스듬히 |
| ② 21–39초 | 6비트 킥: 한 주기(양팔 한 번씩)에 발차기 6번, 그중 2번이 강한 킥 |
| ③ 39–58초 | 대각선 타이밍: 오른손 입수 ↔ 왼발 강한 다운킥, 왼손 입수 ↔ 오른발 강한 다운킥 |
| 58–69초 | 정리 |

## 구성
- 뒤에서 본 어깨·가슴 단면, 골반·다리 단면(발 궤적), 옆에서 본 모습, 팔 단계·롤링·킥 박자 타임라인.
- 팔 경로는 `../freestyle_pull/pull_model.py` 를 재사용하고, 롤링(x축 회전)과 다리 변위를 더한 3D 막대 인형을 투영한다.
- `python3 render.py` 로 다시 만들고, `PREVIEW=10,20 python3 render.py` 로 프레임 PNG만 확인할 수 있다.

코칭에서 쓰는 전형적인 패턴을 단순화한 애니메이션이며(물리 계산 아님), 각도와 타이밍은 사람마다 다르다.
