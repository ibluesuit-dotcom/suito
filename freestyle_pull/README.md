# 자유형 손 젓기 추진 원리 영상

`freestyle_pull_propulsion.mp4` (1280×720, 30fps, 약 89초) — 옆에서 본 시점

| 구간 | 내용 |
|---|---|
| 0–5초 | 타이틀 |
| ① 5–22초 | 동작: 엔트리 → 캐치 → 풀 → 푸시 → 리커버리, 몸 기준/물 기준 손 궤적 |
| ② 22–44초 | 힘: 손·아래팔이 물을 미는 힘과 반작용, 추진력 그래프, 최대 추진 순간, 부위별 비율 |
| ③ 44–62초 | 물의 흐름: 물 입자, 소용돌이, 뒤로 밀려나는 물 |
| ④ 62–78초 | 높은 팔꿈치 vs 팔꿈치가 떨어진 스트로크 비교 |
| 78–89초 | 정리 |

## 모델
- `pull_model.py`: 어깨 기준 손목·팔꿈치 경로를 매끄러운 함수로 정의(물속에서 점점 가속),
  분절별 압력 항력으로 물의 힘 추정(손바닥이 가장 넓은 면), 손·아래팔이 물에 준 운동량만큼
  와류쌍을 넣는 와류법 후류 시뮬레이션(수면은 거울상 와류로 처리).
- `render.py`: matplotlib + ffmpeg 렌더러. `python3 render.py` 로 다시 만들고,
  `PREVIEW=10,20 python3 render.py` 로 해당 시각 프레임만 PNG로 확인한다.

옆에서 본 평면만 다룬 단순화한 교육용 모델이며, 힘의 크기는 상대값이다.
