# 자유형 발차기 추진 원리 영상

`freestyle_kick_propulsion.mp4` (1280×720, 30fps, 약 81초)

| 구간 | 내용 |
|---|---|
| 0–5초 | 타이틀 |
| ① 5–18초 | 발차기 동작: 고관절 → 무릎 → 발목 → 발끝으로 이어지는 채찍 동작, 다운킥/업킥, 발끝 궤적 |
| ② 18–36초 | 작용·반작용: 발이 물을 미는 힘 / 물이 발을 되미는 힘, 앞쪽 성분(추진력), 시간에 따른 추진력 그래프 |
| ③ 36–56초 | 물의 흐름: 물 입자, 발끝에서 떨어지는 소용돌이(역 카르만 와열), 뒤로 뿜어지는 제트 |
| ④ 56–71초 | 유연한 발목 vs 뻣뻣한 발목 추진력 비교 |
| 71–81초 | 정리 |

## 모델
- `kick_model.py`: 2차원 다리 운동학(허벅지·정강이·발), 분절별 압력 항력 `F ∝ |v_n| v_n` 로 물의 힘 추정,
  발의 수직 하중을 결합 순환으로 보고 변화량만큼 발끝에서 와류를 방출하는 간단한 와류법(vortex blob) 시뮬레이션.
- `render.py`: matplotlib + ffmpeg 렌더러. `python3 render.py` 로 영상을 다시 만든다.
  `PREVIEW=10,20 python3 render.py` 로 해당 시각의 프레임만 PNG로 확인할 수 있다.

단순화한 교육용 모델이며 힘의 크기는 상대값이다.
